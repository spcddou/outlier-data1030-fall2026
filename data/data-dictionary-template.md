# Data dictionary template

No final dataset has been collected. Fill in **every column**, including ID and target, after the topic is selected.

| Column | Meaning | Variable type | Unit / categories and order | Role (ID / feature / target) | Available at prediction time? | Missing-value handling |
|---|---|---|---|---|---|---|

For continuous variables, state the measurement unit. For ordinal variables, list categories and their order. For categorical variables, describe categories. Numeric-looking IDs and ZIP codes are not automatically continuous predictors.

Record source URL, API/query parameters, retrieval timestamp, observation period, raw/processed row counts, exclusions, and changes introduced during cleaning. Preserve source definitions and distinguish source variables from derived variables.
